***7/11/26 - ??/??/??:***
***Version 1.6 - The Edge of Shadow:***
*Additions*
-Added Willo character.
    -Willo primarily uses her candy corn revolver and traps to trip up the competition.
-Added Roaring Knight character.
    -The Roaring Knight floats and speeds through the arena, using its explosive stars to oppress enemies.
-Added Freddy Fazbear character.
    -Freddy lurks in the shadows, gaining strength the darker it is. His ability will take out all non-flame lights.
-Added Jack Torrance skin for Springtrap.
-Added "Five Nights at Freddy's" tab to kit menu.
-Added "Overlook Maze" map as a Halloween and Christmas variant for the "Maze" map.
-Added small audio cue when a player with resistance takes damage.
-Added subtitles to all gameplay audio.

*Changes*
-Updated map to 26.3.
-There are no more I-frames.
-Map Countdown now always counts down, and will only stop when the party leader pauses.
-Removed glowing effect when crouching in game.
-All players are now invisible, forcing players to search for their enemy.
    -This is toggleable, though Willo will always be invisible as part of her kit.
-Characters now have animations when using abilities.
    -"whack" for successful abilities, "none" for failed abilities, and "stab" for sabotaged abilities.
-Messages for when a player ends another killstreak now dynamically shows the real killstreak (instead of just 3 or 5).
-Skin menu is now organized the same as the kit menu.
-Harvest now uses the Dappled Forest biome, and features Poplar trees.
-Moved a vending machine on Maze so it wasn't right next to a jump pad.
-Beds can no longer be slept in.
-Signs on San Ricardo are now properly waxed.
-Added grayscale post effect for the void.

*Bug Fixes*
-Fixed bug where Clairen's ability would not be properly empowered.
-Fixed bug where Bogo's hurt sound would not play.
-Fixed bug where the lobby display label would not display on returning from map select
-Fixed bug where Roxanne Wolf's skin could not be selected.
-Fixed bug where final pylon's timer would appear blank.
-Fixed bug where Jerma's randomized sword could bypass Puss's ability.

*Internal Changes*
-Updated Advancements and Predicates to follow new 26.3 syntaxes.
-Chunks are now dynamically forceloaded, hopefully offering better performance for the server.
-Some entities are now loaded and tested via hardcoded UUIDs, rather than dynamic tests. This affects KOTH, CTF, and the lobby.
-Abilities now run through "returns", reducing entity checks.
-Zombie, Impostor, and Hollow Knight ability validity checks now happen on ability execution, rather than their constants.
-Reorganized Clairen's field-state tests to run based on if players are nearby, rather than all the time.
-Clairen's per-tick ability field check now runs through a centralized using "inField" tag and nesting returns, rather than every variant at once.
-Clairen's field timer is now set on the field's spawn, rather than checking every tick for a tag inside its entity function.
-Team checks are now done through the "#main" fake player. They are set on ability use, tested, then reset. This removes the previous second player check.
-Merged the player checks in relevant abilities to check once and never add the "hit" tags for teammates, rather than give all players the "hit" and remove for teammates.
-Moved many per-player timers over to a contexted scheduling system.
    -This prevents removes checks for characters abilities who aren't even in the game, and technically makes them independent from overall game functions.
-Rebuilt internal kit system.
    -ALL characters are now saved in an internal "du-in:kit" storage with compounded storages. Info about each kit is saved, copied, and pulled.
    -The dynamic tests ("/go" functions) now search for "$(id)" instead of "$(kit)".
    -"kit/all/random/set" no longer searches each "kit" score, and can now find the correct kit via indexing its "kit.id" from the database.
    -Random roll is now dynamic, automatically adding to the max value for every kit not in groups "unlock" or "easter_egg"
    -Legendary random roll is also dynamic, automatically adding to the random max value for every kit in "unlock".
-Secondaries are now standardized through a "hasSecond" tag (added on kit pick), and dynamic "secondary/item" and "secondary/init" functions.
    -Per-tick "secKitActions" tag check is being phased out, but technically still supported.
-Secondary give/return functions are now run every second, rather than every tick (like weapons and armor).
-"triCounts" are now tested every second, and are standardized via "secondary/tracker/item".
    -Only exceptions are Pawbert and PearApplez, as their trackers are unique.
-Deprecated "weapCount", "secCount", "triCount", "appleCount", and "tridentCount" scores, now uses "execute unless items" to test for missing items.
-Jack Horner's run functions now operate off his constant function, rather than deferring to "run" functions.
-Ingame music now runs through returns.
-Gamemode functions run through returns
-"new_player" check is now run through a ticking advancement instead of a constant score check.
-Moved game shutdown functions into "ingame/scheduled", as they aren't needed or used in the lobby.
-Moved "team_enable" and "team_disable" into a single check using returns.
-Moved "count_stop" and "count_go" into a single check using returns.
-"Team mode" lobby hotbar icon is now scheduled every second, rather than running every tick.
-The "two_sec_loop" scheduled function in lobby now only runs in Map Select, as it's the only lobby where it's used.
-Moved "main" player count checks to be event based in the lobby. Ingame, they have been moved to run every second, rather than every tick.
-Simplified game cap functions as they did unnecessary checks and math.
-Moved "shutdown" system to schedules, rather than a score-based tick timer. (Deprecated "shutdownTimer" score)
-Map select is now fully scalable, running off of inset scores from UUIDs, rather than tags.
-Default classic, Team, Timed, and Timed Team classic is now event-based.
-Restructured constants for kits using returns.
-Created "Macro-Assisted Schedules", which dynamically front-load timers for timed mode.
-Added "overworld" and "overworld_caves" dimension_types to alter overworld environment attributes.
-Added Glass Panes to "minecraft:glass" block tags.
-Added du-in:retro, du-in:goner, du-in:bw, and du-in:flash posteffects.
-Moved Runza eating test to an advancement.
-Added "du-in:effect/has_resistance" predicate.
-Added "kit/all/game_start/" functions, allowing all characters to have a function that runs on game start without hardcoded tests.
    -Every character folder now has a "(kit)/events/game_start" file, which runs the moment a game starts (but before "intro").
-Added "kit/all/reset/" functions. All characters now run their end of game resets independently, which is less optimized in some ways, but allows for easier management of per-character resets.
    -Every character folder now has a "(kit)/events/reset" file which runs their resets on game end / pre-game start.
-Added room.Between
-Renamed "oldPack" tag for beta music to "beta".
-Renamed "music/ingame/oldpack/" and "music/lobby/oldpack/" to "music/ingame/beta/" and "music/lobby/beta/".
-Renamed and moved audio sources from "minecraft:" to "du-in:".
