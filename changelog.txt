***7/11/26 - ??/??/??:***
***Version 1.6 - The Last Autumn:***
*Additions*
-Added Willo character.
-Added Jack Torrance skin for Springtrap.
-Added small audio cue when a player with resistance takes damage.
-Added subtitles to all gameplay audio.

*Changes*
-Updated map to 26.3.
-There are no more I-frames.
-Removed glowing effect when crouching in game.
-Characters now have animations when using abilities.
    -"whack" for successful abilities, "none" for failed abilities, and "stab" for sabotaged abilities.
-Skin menu is now organized the same as the kit menu.
-Harvest now uses the Dappled Forest biome, and features Poplar trees.
-Beds can no longer be slept in.
-Signs on San Ricardo are now properly waxed.
-Added grayscale post effect for the void.

*Bug Fixes*
-Fixed bug where Bogo's hurt sound would not play.
-Fixed bug where the lobby display label would not display on returning from map select
-Fixed bug where Roxanne Wolf's skin could not be selected.

*Internal Changes*
-Updated Advancements and Predicates to follow new 26.3 syntaxes.
-Chunks are now dynamically forceloaded, offering better performance for the server.
-Some entities are now loaded and tested via hardcoded UUIDs, rather than dynamic tests. This provides optimizations to KOTH, CTF, and the lobby.
-Abilities now run through "returns", reducing entity checks for optimizations.
-Ingame music now runs through returns, offering some optimization.
-Gamemode functions run through returns, offering minor optimization.
-Map select is now fully scalable, running off of inset scores from UUIDs, rather than tags.
-Default classic and Team classic is event-based, offering some optimizations.
-Restructured constants for kits using returns for some optimizations.
-Created "Macro-Assisted Schedules", which dynamically front-load timers for timed mode and provide some optimizations.
-Added "overworld" and "overworld_caves" dimension_types to alter overworld environment attributes.
-Added Glass Panes to "minecraft:glass" block tags.
-Added du-in:retro, du-in:goner, du-in:bw, and du-in:flash posteffects.
-Moved Runza eating test to an advancement.
-Added "du-in:effect/has_resistance" predicate.
-Added room.Between
-Renamed "oldPack" tag for beta music to "beta".
-Renamed "music/ingame/oldpack/" and "music/lobby/oldpack/" to "music/ingame/beta/" and "music/lobby/beta/".
-Renamed and moved audio sources from "minecraft:" to "du-in:".
-Renamed several music files.
    -"ffa" and "ffaend" are now "classic" and "classic_end" (this goes for Beta and Legacy variants)
    -"dm" and "dmend" are now "deathmatch" and "deathmatch_end"
    -"cqend" is now "conquest_end"
    -"kothend" is now "koth_end"
    -"ctfend" is now "ctf_end"
    -"tournamentffa" and "tournamentffaend" are now "tournament" and "tournament_end"
    -"tournament.lobby" is now "tournament_lobby"
    -"oldmusic." is now "music.beta."
    -"music.win.generic" is now "music.win"
    -"big.chungus" and "big.chungus.end" is now "music.big_chungus" and "music.big_chungus_end"
-Simplified ambient sound names.
    -"ambient.forestamb" is now "ambient.forest" 
    -"ambient.desertamb" is now "ambient.desert"
    -"ambient.caveamb" is now "ambient.cave" (possible now that is uses "du-in:" namespacing)
    -"ambient.jungleamb" is now "ambient.jungle"
    -"ambient.nightamb" is now "ambient.night"
-Renamed all kit sound effects to be under "du-in:kit.[kit].[sound]".
-All skin menu functions now run through individual kits' "du-in:kit/[kit]/menu/skins/" folder.
